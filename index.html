Sherman Nagel Result Portal

Role-based school result infrastructure where teachers enter scores, administrators manage academic records, students redeem secure scratch-card PINs, and anyone can verify a printed result.

  • Secure staff access with JWT cookies, bcrypt, optional TOTP 2FA, account lockout, and session revocation.
  • Built for the full result lifecycle: score entry, publishing, analytics, scratch cards, CSV export, guardian emails, and QR verification.
  • Publication-safe placement: a class or arm change that would rewrite already-published results is blocked until the principal explicitly confirms it.
  • Transactional end-of-session promotion that reports every student it could not place (missing or unmapped class) instead of silently skipping them.

05Systems / CLI

GitHub Secrets Watcher

A command-line security tool that scans GitHub repositories (public and private, with a token) for environment and configuration files accidentally committed in Git history, and reports them without modifying anything.

  • A fast history walker diffs each commit against its first parent, so scanning cost scales with what changed, not depth times tree size; deleted files are traced back to the commit that last contained them, and content is probed so likely-secret files are ranked above name-only matches.
  • Persistent bare-clone cache with incremental fetches cuts repeat full-history scans to just a fetch of new commits, and an opt-in early-exit heuristic skips quiet stretches of history.
  • Multi-threaded scanning with an optional GitHub token for higher rate limits and private access, and a history depth that defaults to the entire reachable history.
  • Reports each finding with a validated, URL-encoded link to the exact commit in text, JSON (with per-repo scan stats), or CSV - read-only everywhere, it never edits a repository.
